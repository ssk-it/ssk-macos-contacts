# Conventions

- **Language.** Everything in the repository is in English: code, comments, documentation, commits.
- **Naming.** Rust's own: `snake_case` functions, `CamelCase` types. Names say what a thing is for the caller.
- **Comments.** Say why, not what: the reason a block is sound, the constraint a choice follows.
- **Commits.** Conventional prefixes (`feat:`, `fix:`, `docs:`, `build:`, `ci:`), an imperative subject, a body that says why; 72 columns.
- **Markdown.** No hard line breaks in what GitHub renders: a paragraph is one line.
- **Licence.** Every file is under the Mozilla Public License 2.0 (`LICENSE`).
